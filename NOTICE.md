# Notice

## Images

Event images are not stored in this repository. Each event file points at an image on Wikimedia Commons in its `image` frontmatter (`url`, `credit`, `licence`). The licence recorded in that file is the licence of that image: CC0, Public domain, CC BY or CC BY-SA, in the versions the file states. The credit line names the author as shown on the Commons file page.

Reusing an image outside Human Era means following its licence and its credit line. The CC BY-SA 4.0 licence of `content/` does not apply to the images.

## Text

Event text is written in original wording from the cited Wikipedia articles. Wikipedia text is available under CC BY-SA 4.0, and the articles cited in each file are the attribution trail.

## Scenes

The SVG files in `content/scenes/` are original art by the Human Era contributors under CC BY-SA 4.0.
